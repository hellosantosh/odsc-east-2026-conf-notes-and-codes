Most data teams answer less than half the questions their business asks. Not because the questions are hard. Because the mechanics are slow. Writing SQL, checking joins, building charts, formatting decks. Eighty percent of an analyst's time goes to mechanics. Twenty percent goes to thinking. The ratio needs to flip. This workshop shows you how to build an AI analyst system in Claude Code that handles the mechanics so you can focus on the thinking. No Python required. No SQL required. You configure the system in plain English and teach it how to reason about your domain. We'll build a working AI analyst from scratch using an open-source framework (github.com/ai-analyst-lab/ai-analyst). You'll see how CLAUDE.md works as an analytical persona, how agents and skills create behavioral guardrails, how a correction flywheel turns every mistake into compounding institutional knowledge, and how a four-layer validation pipeline catches the failures that matter most. By the end of the session, you'll understand the architecture well enough to replicate it on your own data. You'll also have access to the open-source repo that powers the system we demo, so you can clone it and start building the same day. This is not a demo of someone else's product. This is a system you build, own, and control. The only person who should automate your job is you.
