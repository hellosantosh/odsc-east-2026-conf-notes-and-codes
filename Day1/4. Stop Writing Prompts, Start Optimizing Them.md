Prompt engineering is a time-consuming and frustrating process of trial-and-error, especially when done without an evaluation set or structured feedback from domain experts. For an agent that needs to give grounded answers, invoke tools properly, or match specific output formats, prompt quality directly determines whether users get reliable answers or are able to trust the system at all. This demo session shows how prompt engineering becomes an automated optimization process using MLflow and Databricks. We show how to apply LLM judges to a classic agent use case, how to define an evaluation set, and how to automatically optimize prompts against gold-standard target answers. Key Takeaways: How to define an evaluation set and use prebuilt LLM judges — such as correctness, completeness, retrieval metrics, and tool call efficiency — to measure agent quality systematically How GEPA, a prompt optimization algorithm available in MLflow, uses LLM-driven reflection to optimize prompts against an evaluation set without any human rewriting needed How to use MLflow to incorporate subject-matter expert feedback into an evaluation set and continuously benchmark and improve prompt quality over time Whether it’s tuning a single prompt or a complex agentic workflow, this session will equip the audience to turn prompt engineering from a manual process into a measurable optimization loop.
