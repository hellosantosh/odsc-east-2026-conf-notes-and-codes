This session introduces Deep Agents, an open-source agent harness built on LangChain and LangGraph that brings professional-grade agentic capabilities to your Python applications. Deep Agents implements three core principles seen in agent harnesses like Claude Code: structured planning (before task execution), computer access (filesystem and shell operations), and sub-agent delegation (for isolated, parallel task execution). In this session, we'll explore: The middleware architecture that powers Deep Agents' built-in tools (todo management, file operations, sub-agent spawning) How to extend agents with custom models, tools, and instructions Practical patterns for human-in-the-loop workflows and long-term memory I'm looking forward to having you join me on this deep dive into deep agents!
