The default assumption in agent development is that you need the biggest, most expensive model available. That assumption is increasingly wrong. Open source models at 9B-30B parameters are closing the gap on frontier performance, and with the right infrastructure, they can handle complex multi-step workflows at a fraction of the cost with improved accuracy. In this workshop, you will build working agents from scratch using the Subconscious platform across three core capabilities: browser automation (navigating and taking action on live websites), CLI tool use (executing shell commands within agent loops), and MCP integration (connecting agents to external services via the Model Context Protocol). Under the hood, we will show how context intelligence allows small models to manage their own context windows during inference, pruning irrelevant information so agents stay sharp across long, multi-step tasks. This is the same approach that posted 70% on WebArena and 68% on OSWorld with dramatically lower compute. The session targets ML engineers, backend developers, and applied AI practitioners building agent systems for production. You will leave with working code, a GitHub repo, and a practical framework for deciding when small models can replace frontier APIs in your own workflows.
